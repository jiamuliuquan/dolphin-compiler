静态类型 · 编译为本机代码

一门可以亲手写编译器的语言

Dolphin 是一门面向学习与实践的静态类型语言，语法参考 Rust、Kotlin、Java 和 C。编译器用 Rust 写成，默认通过 Cranelift 生成本机可执行文件，也可选用 LLVM 后端。

    var values = [1, 2, 3, 4];

    values[1] = 10;

    for value in values {
        println("Hello, {} — value = {}", name, value);
    }

为什么选择 Dolphin

为理解编译器而设计

从词法分析到本机代码生成的每个阶段都拆成独立 crate，源码标准库也用 Dolphin 写成，读语言和读实现可以同步进行。

◈

静态类型，错误前置

完整的类型检查、控制流检查与返回路径检查，尽量在编译期发现错误，运行时只保留明确的陷阱。

◧

显式且安全的内存

Zig 式手动内存模型：没有 GC、RC 与隐式析构，分配与释放显式可见，defer 是唯一的作用域清理语法。

⬡

自包含工具链

发行包内置预编译运行时与 rust-lld 链接器，解压即可构建；链接仍使用系统自带的 CRT/SDK。

◇

泛型与 trait

用户泛型经工作队列单态化，trait 提供静态分派，标准库的 Vec、String、Option、Result 全部由 Dolphin 源码写成。

▤

模块与包管理

多文件项目、pkg/use/pub 可见性，以及 dolphin.toml 清单、path/坐标依赖、确定性 .dlib 包与锁文件。

✦

面向学习

仓库按里程碑提供可运行示例，并如实记录尚未实现的能力，方便按顺序阅读和扩展。

语言预览

简洁、明确的语法

函数、变量、控制流与模式匹配的写法接近 Rust 与 Kotlin，下面是一个完整的面积计算程序。

  • val 与 var 区分不可变与可变绑定，支持局部类型推断。
  • 定长数组、切片、原始指针与显式内存分配。

enum Shape {
    Circle(f64),
    Rectangle(f64, f64),
    Empty,
}

fn area(shape: Shape): f64 {
    return match shape {
        Shape.Circle(r) => 3.14159 * r * r,
        Shape.Rectangle(w, h) => w * h,
        Shape.Empty => 0.0,
    };
}

fn main() {
    println("{}", area(Shape.Circle(2.0)));
}
快速开始

三步运行第一个程序

下载发行包并加入 PATH，然后编译运行任意 Dolphin 项目。

1. 获取编译器

从发行页下载对应平台的归档，解压到任意目录。

tar xzf dolphin-0.3.0-x86_64-unknown-linux-gnu.tar.gz \
  -C ~/.local/dolphin

2. 加入 PATH

把解压目录加入 PATH，确保 dc 与 rust-lld 位于同一目录。

export PATH="$HOME/.local/dolphin:$PATH"
dc --version && dc env

3. 构建并运行

dc test 运行库测试，dc build 构建应用；产物写入项目的 target/ 目录。

dc test examples/m19/textstats
dc build examples/m19/dtext --bin dtext
printf 'alpha\nbeta\n' | ./examples/m19/dtext/target/dtext --filter beta

发行包内容

dc 与 rust-lld 必须位于同一目录；macOS 与 Linux 包还携带 rust-lld 依赖的 LLVM 动态库，请勿拆分。
