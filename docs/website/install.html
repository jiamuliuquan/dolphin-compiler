安装 Dolphin

Dolphin 以自包含发行包发布：解压后即可使用，不需要 Rust 或编译器源码；链接仍使用系统自带的 CRT/SDK。

系统要求

Linux x86_64、macOS ARM64（Apple Silicon）与 Windows x86_64 为一级支持平台，均在 CI 中完成构建与端到端测试。

PlatformTarget tripleArchive
Linux x86_64x86_64-unknown-linux-gnu.tar.gz
macOS ARM64aarch64-apple-darwin.tar.gz
Windows x86_64x86_64-pc-windows-msvc.zip

1. 下载归档

curl -LO https://github.com/foxlab/dolphin-compiler/releases/download/v0.3.0/dolphin-0.3.0-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/foxlab/dolphin-compiler/releases/download/v0.3.0/dolphin-0.3.0-x86_64-unknown-linux-gnu.sha256

2. 校验完整性

sha256sum -c dolphin-0.3.0-x86_64-unknown-linux-gnu.sha256

3. 解压并加入 PATH

mkdir -p ~/.local/dolphin
tar xzf dolphin-0.3.0-x86_64-unknown-linux-gnu.tar.gz -C ~/.local/dolphin
echo 'export PATH="$HOME/.local/dolphin:$PATH"' >> ~/.bashrc

4. 验证安装

dc --version
dc env

1. 下载归档

curl -LO https://github.com/foxlab/dolphin-compiler/releases/download/v0.3.0/dolphin-0.3.0-aarch64-apple-darwin.tar.gz
curl -LO https://github.com/foxlab/dolphin-compiler/releases/download/v0.3.0/dolphin-0.3.0-aarch64-apple-darwin.sha256

2. 校验完整性

shasum -a 256 -c dolphin-0.3.0-aarch64-apple-darwin.sha256

3. 解压并加入 PATH

mkdir -p ~/.local/dolphin
tar xzf dolphin-0.3.0-aarch64-apple-darwin.tar.gz -C ~/.local/dolphin
echo 'export PATH="$HOME/.local/dolphin:$PATH"' >> ~/.zshrc

4. 验证安装

dc --version
dc env

1. 下载归档

Invoke-WebRequest -Uri https://github.com/foxlab/dolphin-compiler/releases/download/v0.3.0/dolphin-0.3.0-x86_64-pc-windows-msvc.zip `
  -OutFile dolphin-0.3.0-x86_64-pc-windows-msvc.zip

2. 校验完整性

Get-FileHash dolphin-0.3.0-x86_64-pc-windows-msvc.zip -Algorithm SHA256

3. 解压并加入 PATH

Expand-Archive dolphin-0.3.0-x86_64-pc-windows-msvc.zip `
  -DestinationPath "$env:USERPROFILE\dolphin"
$env:Path = "$env:USERPROFILE\dolphin;$env:Path"

4. 验证安装

dc --version
dc env

发行包内容

dc 与 rust-lld 必须位于同一目录；macOS 与 Linux 包还携带 rust-lld 依赖的 LLVM 动态库，请勿拆分。

FileDescription
dcCompiler entry point / 编译器主命令
dolphin-compilerAlias of dc / 兼容名称
rust-lldBundled linker (LLD) / 自带链接器
libLLVM.dylib, libLLVM.so.*Linker runtime (macOS / Linux) / 链接器动态依赖
LICENSEGPL-3.0
README.mdRelease notes

离线使用

在不声明远程依赖时，dc check/build/run/test 不会访问网络。运行时目标文件内嵌于 dc，链接器为同目录的 rust-lld。使用 Maven 风格依赖时，dc 会通过 HTTPS 下载 .dlib 到内容寻址缓存（DOLPHIN_HOME，默认 ~/.dolphin），并写入 dolphin.lock。 

dc build my-project --locked --offline

升级与卸载

升级：用新版本覆盖旧目录，或解压到新目录后替换 PATH。卸载：删除发行目录并从 PATH 移除对应条目即可，Dolphin 不写注册表、不创建系统服务。

说明

  • 构建程序时仍会动态链接操作系统自带组件（Linux glibc、macOS libSystem、Windows UCRT）。
  • 从源码构建编译器自身才需要 Rust 与本机 C 编译器。
  • 当前不支持交叉编译，编译器只生成宿主平台的本机程序。
